## Реализация

| Функция | Где | Поведение |
|---|---|---|
| История | NovelSession.StorySay, MenuNavigation.OpenHistory | FIFO до 250 записей в StateCore. Запись добавляется при предъявлении Say. Откат и загрузка восстанавливают историю из snapshot, поэтому записи не дублируются. Текст без тегов (DialogueProgram.plain), имя окрашено цветом говорящего. Открывается на последней записи (normalized 0). |
| Откат | NovelSession.RememberInteraction/Rollback | До 100 независимых NovelCore без вложенного кольца. Текст восстанавливается полностью показанным, переходы и bounce завершены, Sfx/Voice остановлены. read IDs профиля не уменьшаются. |
| Барьер | StoryRunner.Barrier → StoryBarrier | Очищает кольцо checkpoints: пройти назад нельзя. Кнопка «Назад» отражает CanRollback(). |
| Пропуск | NovelSession.ReadingTick | Toggle (кнопка) и hold (Ctrl). Не более 30 Say/с. Непрочитанное только при skip_unseen. На выборе ждёт пользователя. После выбора продолжает только при skip_after_choices. Переходы пропускает только при skip_transitions. |
| Авто | NovelSession.ReadingTick | delay = afm_time·(graphemes+25)/250 после полного показа и пауз. Явный {w} ждёт ввода. Выбор не принимается автоматически. |
| Скрытие UI | NovelSession.SetUiHidden, NovelView.SetHidden | H или нажатие колеса (СКМ) скрывает ADV/NVL, выборы, quick menu и индикатор пропуска. Первый следующий ввод (ЛКМ/Space/Enter/H/СКМ) только возвращает интерфейс. Новая реплика или меню выбора, откат, загрузка и игровое меню возвращают UI. Пока UI скрыт, skip/auto стоят. |
| Полный экран | MenuNavigation.SetFullscreenMode | Кнопки в настройках и Alt+Enter. Значение сохраняется в профиле. При зажатом Alt Enter не продвигает сценарий и не активирует кнопки. |
| Фокус окна | NovelSession.Paused/Update | Без фокуса таймеры, текст и audio-время заморожены. После возврата действует input barrier 0.1 с. |

## Режимы

| Из → событие | Результат |
|---|---|
| Normal → кнопка Skip / Ctrl | Skip (Auto выключается) |
| Skip → ручное продвижение | Toggle skip выключен; hold действует, пока зажат Ctrl |
| Skip → выбор | Ждёт пользователя; после выбора skip сохраняется только при skip_after_choices |
| Normal → кнопка Auto | Auto (skip выключен) |
| Auto → ручное продвижение | Реплика переключается, Auto остаётся |
| Skip/Auto → меню, история, модальное окно, потеря фокуса | Приостановлены, не сброшены |
| Skip/Auto → откат, загрузка, новая игра | Выключены |
| Любой → H/СКМ | UI скрыт, skip/auto стоят |

## Управление v1

| Ввод | Действие |
|---|---|
| ЛКМ по игровой области, Space, Enter | Дальше (или вернуть скрытый UI) |
| ПКМ, Escape | В игре открывают настройки поверх кадра новеллы; в меню — назад; закрывают историю |
| Колесо вверх, PageUp | Откат |
| Ctrl (удержание) | Пропуск |
| H, СКМ | Скрыть/показать интерфейс |
| Tab, стрелки | Фокус UI (не пропуск) |
| Alt+Enter | Полный экран / окно |

Экран «Помощь» в MainMenu.scene обновлён под этот набор.

Настройки, открытые из quick menu (кнопка «Настройки», а также «Сохранить» и «Загрузить»), появляются поверх игры без показа навигации игрового меню. «Назад» возвращает сразу в игру.

## Ожидает проверки пользователем

1. СКМ и H: скрыть, затем ЛКМ возвращает UI без смены реплики; то же на выборе.
2. Quick menu → «Настройки», «Сохранить», «Загрузить»: главное меню не мигает; «Назад» возвращает в игру.
3. Сохранение на выборе → загрузка: высота плашек соответствует тексту (раскладка пересчитывается каждый кадр по фактическим границам текста).
4. Alt+Enter в игре и меню; ПКМ в игре, в истории и в подменю.
5. История: открывается на последней реплике, имена цветные; skip/auto после закрытия продолжаются.
6. 101 checkpoint ограничен 100; барьер непроходим; потеря фокуса не продвигает реплику.
