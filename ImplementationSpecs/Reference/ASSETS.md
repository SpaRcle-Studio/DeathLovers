## Формат manifest

`id` перечисляет исходные image-имена и автоматическое имя через `;`; для остальных файлов ID равен исходному относительному пути. `source` отсчитывается от game; `target` от DeathLovers. В целевой поставке Images/Audio/UI/Fonts расположены под Resources/DeathLovers. Это декларация будущего импорта, а не подтверждение уже скопированных файлов. Конвертер назначит стабильные runtime-ID на этапе 04; текущие ID сохраняют написание оригинала, включая `dissapointed`.

PNG dimensions и наличие alpha-channel прочитаны из IHDR встроенным файловым reader .NET; наличие канала не означает, что в нем есть прозрачные пиксели. Для цветовых типов без alpha возможный tRNS не исследован — это явно указано. Длительности аудио не измерялись: аудиодекодер не запускался; `not-measured` не означает нулевую длительность. Нужна пользовательская проверка длительности/зацикливания. Размеры приведены для PNG, остальные поля неприменимы для звуков и шрифтов.

`directReferences` — текстовые обращения к пути, а не окончательное доказательство использования: image-объявление само по себе не делает ресурс достижимым. `usage` отдельно отмечает достижимые сюжетные изображения/звуки, debug и кандидатов. Шаблонные пути GUI `[prefix_]` и системный шрифт отдельно описаны ниже. Отсутствие прямой ссылки не является разрешением удалить файл.

## Реальное разрешение Ren’Py

Проверены локальные исходники SDK `C:/Work/Programs/RenPy/renpy-8.4.1-sdk/renpy` (только чтение):

- `common/00images.rpy:31–83`: автоматическое имя изображения — basename без расширения в нижнем регистре, каталоги не входят в имя; явное имя с приоритетом. Поэтому `scene corridor`, `god`, `darkness`, `gpt`, `office`, `dumpster`, `waroff`, `diner` законны. Все 40 обращений scene разрешены однозначно либо относятся к встроенному `black`. Не добавлять ложные alias для этих имен.
- `audio/audio.py:67–73`, `loader.py:653–679`: load с directory="audio" проверяет обычные префиксы, затем audio/. Для каждого буквального пути из сюжета/настроек есть ровно один физический файл; `music/office.ogg` не выбирает соседний office.wav. `audio/music/main_menu.ogg` уже полный относительный путь.
- `images/background/corridor.PNG` и `badend.PNG` отличаются регистром расширения от явных ссылок `.png`. На целевой Windows файловое разрешение без учета регистра дает единственную цель. При переносе зафиксировать физическое написание в manifest; не создавать вторые копии и не полагаться на регистр для выбора ресурса. См. D007.

Сюжет использует 44 уникальных физических изображения (scene и состояния героинь, включая empty), 29 уникальных аудиофайлов с учетом музыки меню, активного/default voice и NVL. 43 аудиофайла — полный физический реестр, не количество используемых дорожек. У каждого достижимого set_state найдена декларация; неизвестных состояний нет.

Голоса: ch_narrator→narrator.wav, ch_oth→voice.wav, ch_news→news.wav, ch_r→revecca.wav, ch_death→death.wav, ch_god→god.wav, ch_p→plague.wav, ch_w→war.wav, ch_h→hunger.wav; NVL→deathnarrator.wav. Не переносить `audio/sfx/single_type.wav` как обязательный файл: единственное упоминание — внутри закомментированного хвоста character_data.py:133. alice.wav отсутствует, но Алиса доступна только в исключенном debug.
