# Дефекты и решения переноса

Этап 06, 17.11.2026: D003 исправлен в AS NovelAudio: десять непозиционных AudioSource Typewriter0…Typewriter9, индекс (index+1)%10, без Typewriter10. Звук вызывается только при показе непробельной графемы, не при разборе тега/ускорении/перерисовке. Интервал max(1/effectiveTextCps, .075*speakerMultiplier); выключенный pixel_voice и cps<=0 отключают звук. Выполнение и слуховая проверка — AWAITING_USER_RUN.

D002: AS NovelSession/NovelView реализуют требуемый NVL напрямую, без call_in_new_context. Слова оригинала сохранены; состояние и история отдельны для каждого Say. Из-за исходного блокера точное совпадение переполнения с работающим оригиналом не заявляется: требуется пользовательский Reference-кадр/решение D002.

Этап 05, 16.11.2026: D001 исправлен в представлении порта классом MenuParallax (AngelScript): состояние принадлежит экземпляру, Python/global не используется. Дополнительное явное отличие: исходник растягивает слои 2594×1080 до 1920×1080, но 05_MAIN_MENU требует сохранить пропорции. В порте выбран AspectRatioFitter EnvelopeParent с центральной обрезкой избыточной ширины; семь prescale сохранены. Это приоритет требования этапа 05, а не заявленное пиксельное совпадение с растянутым оригиналом. D008 остается открытым: версия 1.0 не выведена из комментария, строка версии главного меню пустая.

Обновление 16.11.2026: D004 и D006 исправлены в оригинальном script.rpy по прямому запросу пользователя. D004: переход к ending перед меню при var_roots==3. D006: исправлен закрывающий тег курсива и `[x3]` экранирован как `[[x3]`. Проверка графа этапа 04 не обнаружила достижимого пустого выбора; нормализованный Story-текст содержит буквальное `[x3]`. Подробности и hash принятого источника — SOURCE_REVISIONS.md. Строки и формулировки таблицы ниже сохраняют историческую диагностику до исправления; эти два пункта больше не ожидают сюжетного решения. Ren'Py runtime этим офлайн-прогоном не проверен.

Все воспроизведения ниже — точные статические условия и инструкции для пользователя, **не выполненный запуск**. Исходная игра не изменялась. Блокеры исходника не дают права молча менять сюжет; кадры из несовпадающей `.rpyc` не подтверждают текущие `.rpy`.
