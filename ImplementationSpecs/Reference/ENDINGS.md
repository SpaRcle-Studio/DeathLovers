# Концовки и маршруты

Порядок битов таблицы: P=var_plague_score>=5, W=var_war_score>=5, H=var_hunger_score>=5. Сравнения взаимоисключающи: каждая строка задает уникальную тройку битов. Все 2^3=8 троек покрыты, при целочисленных очках неопределенных случаев нет. Это доказательство предикатов, не результата запуска.
