# 06. Исполнитель новеллы на AngelScript и вертикальный срез

## Цель и зависимости

Зависимость: 05. Реализовать весь механизм прохождения на AS, а контент пока ограничить репрезентативным фрагментом. Не добавлять в C++ обработчик Say/Choice/Ending. Использовать Story v1 этапа 04 и явное состояние из общих контрактов.

## Обязательные роли

- Session: владеет единственным GameState, профилем и жизненным циклом.
- StoryRunner: читает команды, выполняет branch/call/return/assign и переключает phases.
- DialoguePresenter: ADV/NVL, печать, паузы и видимость.
- CharacterPresenter: применение декларативных состояний персонажей и слоев.
- AudioDirector: игровые каналы, fade и звук печати.
- PresentationRestorer: идемпотентное восстановление без сюжетных side effects.

Это роли AS; не обязательно создавать одноименные классы. Не дублировать state между контроллерами. Render objects — производная от GameState, а не источник сюжетной истины.

## Выполнение команд

При старте новой игры defaults берутся из Variables registry. В Ready runner выполняет невременные команды до первого yield. За кадр максимум 1000 команд; превышение — диагностируемый вероятный цикл с ID, а не зависание. Call кладет returnTarget; Return извлекает его. Choice вычисляет доступность при входе, показывает варианты в исходном порядке и принимает ровно одно действие. Assign происходит ровно в своей позиции и не повторяется при перерисовке/загрузке.

Пауза, переход, диалог и выбор работают через Update/timers, без блокирующих sleep. Открытие game menu/потеря фокуса приостанавливает narrative timers, печать и анимации персонажей. Музыка продолжает играть; позиция в снимке берется фактическая. Закрытие меню не считает прошедшее реальное время временем чтения.

## Диалог и текстовые команды

Первое advance во время печати показывает текст до следующего явного `{w}` без длительности; автоматические и числовые паузы пропускает. Достигнутый waitForInput требует отдельного advance; тот же input не проходит через две границы. При fully shown следующий advance завершает Say. `{nw}` после печати/таймеров завершает Say автоматически. Escape не advance.

Поддержать b/i/u/s, size относительный, alpha множительный, cps множительный; stack styles с вложенностью и закрытием по общему контракту. `{w}` — input wait, `{w=N}` — timed wait. Команды тегов не занимают видимых символов. Wave/shake параметры из текста передаются общему renderer.

Алгоритм авто-пауз портировать из `character_data.py:add_auto_waits` буквально по правилам: …→..., знаки `.,;:!?…`, исключение тегов и десятичных точек, поиск существующего wait через пробелы/теги, паузы на последовательностях знаков; wait=0.25. Не заменять на «после каждой точки».

ADV: имя/цвет по Character registry, текст и указатель завершения. NVL: накопление реплик до NvlClear, без вложенного VM-контекста; каждая реплика имеет обычный state/ID и историю. Переполнение страницы воспроизводит зафиксированное поведение оригинала и не теряет строки.

## Персонажи, фон и переходы

Перенести все используемые состояния из characters.rpy/images.rpy. Позиции/scale/flip складываются по реальной формуле оригинала; TODO-комментарий не считать реализованным смещением sprite. Hidden не рисует персонажа и не удаляет его определение. Порядок слоев воспроизводит исходный register order, не сортируется по имени.

Scene не должен случайно скрывать персонажей на отдельных слоях, если Ren’Py сохраняет их. Dissolve состояния применяется к слою персонажа и не затрагивает окно диалога. Одноразовый bounce из исходника: duration=0.2, amplitude=20, offset=-abs(sin(t*pi/duration))*amplitude в Ren’Py Y; после окончания исходная позиция восстановлена, одноразовый флаг сброшен. Фоновый Fade/Dissolve хранит elapsed/duration и исходный/целевой ресурс для восстановления.

## Аудио

Пути voice — логические ID из manifest, не произвольное склеивание неизвестного пути. Пул из 10 непозиционных источников печати, выбираемый по кругу 0..9. Исправить очевидную ошибку исходного выбора typewriter10 при регистрации 0..9; записать в DEFECTS. Минимальный интервал max(1/textCps, 0.075*speakerMultiplier); при cps<=0 или выключенном pixel voice звука нет. Пробел/тег не запускает звук; остановка печати не создает догоняющие звуки.

Музыка и SFX используют независимые bus. Переход gain линейный по игровому времени, пока Reference не зафиксирует другую кривую; fade команды имеют исходную длительность. Восстановление не воспроизводит завершенные одноразовые SFX; длительные loop/музыку восстанавливает с позицией. Если seek пока не работает, это незакрытая зависимость этапа 03, не разрешение начать трек сначала молча.

## Вертикальный срез и приемка

Подключить Start меню к прологу. Fixture должен включать ADV/NVL, auto waits, явный wait, nw/cps, смену состояния с dissolve, bounce, звук/музыку, conditional choice, call/return, assign и barrier. Допустима отдельная тестовая история, но пролог оригинала также должен воспроизводиться.

Проверить восстановление одного и того же snapshot дважды: variables/history/object counts неизменны; никакие команды начисления не повторены. Проверить pause/menu/resize в середине текста и перехода. `Reports/06_RESULT.md` содержит state schema, trace до/после каждой команды fixture и актуальные интерфейсы, необходимые сохранениям. Для еще не выполненного запуска честно указать AWAITING_USER_RUN.
